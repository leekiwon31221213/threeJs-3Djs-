# 학습 자료 저장소

이 저장소는 공부하면서 사용하는 **이미지와 파일을 저장하기 위한 공간**입니다.

학습 내용과 커리큘럼은 아래 노션 페이지에서 확인할 수 있습니다.

## 학습 커리큘럼

[노션에서 공부한 커리큘럼 보기](https://app.notion.com/p/3a466d5ca8e980c19ce3de050b8dc050?v=3a466d5ca8e980479ddb000c7283985d)

## 저장소 용도

- 학습에 사용하는 이미지 보관
- 예제 및 참고 파일 보관
- 노션에서 사용하는 자료 연결

학습 과정과 정리 내용은 노션에서 관리하며, 이 저장소는 관련 자료를 보관하는 용도로 사용합니다.
